# プライバシーポリシー / Privacy Policy — みえるタイマー (Visual Timer)
## 日本語
本拡張機能は個人情報を一切収集・送信しません。タイマー設定などのデータは chrome.storage.local 内にのみ保存され、拡張機能から自動的な外部通信は行いません。任意の購入リンクを押した場合のみ、Stripe の外部ページが新しいタブで開きます。決済情報は Stripe 側で扱われ、本拡張機能は保存しません。トラッキング・広告・第三者提供はありません。拡張機能を削除すると保存データも削除されます。
## English
This extension collects/transmits no personal data. Timer settings and related data are stored only in chrome.storage.local; the extension makes no automatic external network requests. Only if you choose the optional purchase link, a Stripe external page opens in a new tab. Payment information is handled by Stripe and is not stored by this extension. No tracking, ads, or sharing. Uninstalling removes all stored data.
